# 💬 QuoteVault

### Premium Flutter Daily Motivation App

*A beautifully designed Flutter application that delivers inspiring quotes with a clean, modern interface. QuoteVault helps users discover motivation every day through categorized quotes, favorites, search, sharing, and persistent local storage.*

---

# ✨ Features

## 💬 Quotes

- Browse inspirational quotes
- Random quote generator
- Category-based quotes
- Beautiful quote cards
- Author information

---

## ❤️ Favorites

- Save favorite quotes
- Remove favorites
- Persistent favorite storage
- Quick access to saved quotes

---

## 🔍 Search

- Real-time search
- Search by quote
- Search by author
- Instant filtering

---

## 📤 Sharing

- Share quotes with friends
- Copy quotes to clipboard
- One-tap sharing

---

## 🎨 User Experience

- Premium Material 3 UI
- Beautiful Dark Theme
- Smooth animations
- Responsive design
- Splash screen
- Custom app icon

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/abdulwasay-codes/quotevault-flutter-app.git
```

---

## Navigate

```bash
cd quotevault-flutter-app
```

---

## Install Packages

```bash
flutter pub get
```

---

## Run the Application

```bash
flutter run
```
