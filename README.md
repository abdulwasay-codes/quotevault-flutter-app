# QuoteVault Flutter App

A premium motivational quotes application built with Flutter.

## Features

✨ Random motivational quotes

❤️ Favorite quotes with persistent storage

🔍 Search quotes instantly

📂 Browse by categories

📤 Share quotes to social media

🌙 Premium dark UI

🚀 Custom splash screen

📱 Custom app icon

## Built With

* Flutter
* Dart
* SharedPreferences
* Share Plus
* URL Launcher
